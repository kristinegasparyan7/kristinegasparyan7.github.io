# US-see-another (PRD R2)

**Story:**
As a visitor, I want to see a different affirmation if the first one doesn't land, so that I still get one good thought without being handed a whole list to browse.

**Acceptance Criteria:**
- Tapping "Another" replaces the displayed affirmation with a different one from the set.
- Tapping "Another" repeatedly never shows the same affirmation twice in a row.
- At no point are two or more affirmations shown on screen at once — the experience stays single-focus.
- Negative path: if "Another" is tapped enough times to cycle through every affirmation in the set, it wraps back to the start rather than showing a blank state or silently disabling the button.
