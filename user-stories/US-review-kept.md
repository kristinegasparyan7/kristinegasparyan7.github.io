# US-review-kept (PRD R8)

**Story:**
As a visitor, I want to look back through the thoughts I kept, so that I can re-read one that helped without being handed a list to manage.

**Acceptance Criteria:**
- Kept thoughts are reviewed one at a time, in the same single-focus stage — never as a scrollable list or grid.
- A position indicator shows where the user is in the set (e.g. "2 / 5") so the set feels finite and knowable.
- Moving forward and back through kept thoughts is possible by both pointer and keyboard.
- A kept thought can be removed while reviewing it.
- The entry point to review is hidden entirely when nothing has been kept yet, so a first-time visitor sees no extra controls.
- Negative path: removing the last kept thought returns the user to today's thought rather than leaving an empty review screen.
