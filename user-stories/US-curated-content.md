# US-curated-content (PRD R5)

**Story:**
As a visitor, I want the affirmations to feel genuinely good, not generic filler, so that the one thing I get each time is actually worth opening the app for.

**Acceptance Criteria:**
- All content shown comes from the curated affirmation set — no placeholder or auto-generated text ships in v1.
- The content set has enough unique entries that tapping "Another" doesn't visibly repeat within a normal single session.
- Negative path: if the curated set fails to load, the fallback affirmation (see US-fallback-affirmation) is shown instead of blank content.
